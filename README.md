## 关于可靠性

这套资料对**每一条结论**都区分了性质，不混为一谈：

- **纯粹数学推导** —— 可以自己验算，中间步骤都给出。
- **协议实现细节** —— 尽量对照源码（如 v3-core / v4-core）逐条核实，并给出文件链接。
- **市场判断** —— 显式标注是**结构性推理**还是**已验证事实**。

未经核实的内容都会显式标注 ⚠️ **未验证**。
