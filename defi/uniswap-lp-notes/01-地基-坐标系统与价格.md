# 01 · 地基：坐标系统与价格

> **本章回答什么问题**
>
> 1. 一个流动性池，能不能用**一张图**表示清楚？
> 2. `P = y/x` 里的"价格"到底是什么东西？它被存在哪里？谁在改它？
> 3. `x · y = K` 里的 `x`、`y`、`K` 分别是什么量纲？`K` 是价格吗？
> 4. **`K` 什么时候不变、什么时候变？变多少？**（本章重点）
> 5. 不同操作对 `K` 和价格各有什么影响？为什么"非比例加 LP"会同时改掉两个？
>
> 这一章不涉及 V3、V4，也不涉及无常损失。它只做一件事：**把坐标系建起来**。
> 后面所有章节都建立在这一章的图上。

---

## 1.1 为什么需要坐标系

大多数人第一次接触 Uniswap 时，会试图用"价格"来理解池子。这会立刻卡住，因为：

- 池子里**没有存价格**，只存了两个数字：token0 的数量和 token1 的数量。
- 价格是这两个数字**算出来的**。
- 而且这两个数字随时被交易改写。

**与其追一个不断变动的派生量，不如直接盯着那两个原始数字。**

所以第一步：把"池子的两个数字"画成坐标平面上的一个点。

---

## 1.2 状态空间：把池子画成一个点

### 1.2.1 两个轴

我们固定一套坐标（全文通用）：

```
y 轴 = 池中 token1（计价币，本文用 ETH）的数量
x 轴 = 池中 token0（基础币，本文用 A）的数量
```

> **一句话：坐标平面上的每一个点，都代表池子的一种可能状态。**

原点 `(0,0)` 是"空池子"，越往右上走，池子越大。

### 1.2.2 池子的状态必须落在一条曲线上

恒定乘积（Constant Product）规则要求：

$$x \cdot y = K$$

所以在状态平面上，**池子的状态点只能落在这条双曲线上**，不能落在别处。

```
y (ETH 数量)
^
|            ___
|        _--'   '--_
|      -'           '-_        ← xy = K（双曲线，只取第一象限）
|     /      ●                  ● = 池子当前状态 (x, y)
|   -'                            池子只能在这条线上滑动
|  '
+------------------------------------> x (A 数量)
(0,0)
```

这条曲线的形状很关键：**它永远碰不到坐标轴**。

- 越往右走，`x` 越大、`y` 越接近 0，但 `y` 永远不等于 0。
- 越往左走，`x` 越接近 0、`y` 越大，但 `x` 永远不等于 0。

后面会看到，**"碰不到轴"这件事，就是 V2 价格范围是 `(0, ∞)` 的几何原因**（见 [03-V3 集中流动性](03-V3-集中流动性.md)）。

---

## 1.3 价格 = 从原点连到状态点的射线斜率

这是全文最重要的一句话，值得单独推导。

### 1.3.1 定义

我们约定价格定义为**两种储备数量的比值**：

$$P = \frac{y}{x} \quad \text{单位：ETH 每个 A}$$

现在在状态平面上做一件事：**从原点 `(0,0)` 画一条直线，连到池子的状态点 `(x, y)`**。

```
y (ETH)
^
|         ●  ← 池子状态 (x, y)
|        /|
|       / |
|      /  |  y
|     /   |
|    /    |
|   /     |
|  /      |
| /       |
+--+------+----------> x (A)
(0,0)     x
```

这条直线的斜率是：

$$\text{斜率} = \frac{\Delta y}{\Delta x} = \frac{y - 0}{x - 0} = \frac{y}{x} = P$$

> **一句话：池子的价格，就是"从原点连到池子状态点"那条射线的斜率。**
>
> **价格不是池子里的一个字段，而是状态点相对原点的角度。**

### 1.3.2 同一条曲线上的不同点，价格完全不同

取 `K = 1000`，在这条曲线上取几个点（对应主例子 A 所在的曲线族）：

| 池子状态 (x = A, y = ETH) | `K = x·y` | 斜率 `P = y/x` |
|---|---|---|
| 10, 100 | 1000 | **10** |
| 31.62, 31.62 | 1000 | **1** |
| **100, 10** | **1000** | **0.1** ← 主例子 A |
| 316.2, 3.162 | ~1000 | **0.01** |
| 1000, 1 | 1000 | **0.001** |

**注意第一列和最后一列：`K` 完全一样，都是 1000，但价格差了 10000 倍。**

```
y (ETH)
^
|  ● (10, 100) 斜率 10   ← 很陡：A 很贵
|    \
|     \  ● (31.6, 31.6) 斜率 1
|      \
|       \   ● (100, 10) 斜率 0.1   ← 主例子 A
|        \    \
|         \     ● (316, 3.16) 斜率 0.01
|          \      \
|           \       ● (1000, 1) 斜率 0.001
+----------------------------------------> x (A)
(0,0)
```

**射线越陡，A 越贵；射线越平，A 越便宜。**

> **一句话：`K` 决定"点在哪条曲线上"，价格决定"点在曲线的哪一段"。两者是独立的两个自由度。**

### 1.3.3 价格的三个直接推论

从"价格 = 斜率"这个定义，可以直接推出三件事：

**推论 1：价格不是一个独立变量。**

你不可能在不改变 `x` 或 `y` 的前提下改变价格。价格是储备的**函数**，不是储备的**同伴**。

$$P = \frac{y}{x} \quad\Longleftrightarrow\quad \text{改变 } P \text{ 必须改变 } \frac{y}{x}$$

**推论 2：价格可以被反解成储备。**

由 `x·y = K` 和 `y = P·x` 联立：

$$x = \sqrt{\frac{K}{P}}, \qquad y = \sqrt{K \cdot P}$$

验证：

$$x \cdot y = \sqrt{\frac{K}{P}} \cdot \sqrt{KP} = \sqrt{K^2} = K \quad \checkmark$$

$$\frac{y}{x} = \frac{\sqrt{KP}}{\sqrt{K/P}} = \sqrt{P^2} = P \quad \checkmark$$

**推论 3：`(P, K)` 和 `(x, y)` 是描述同一个池子的两套等价坐标。**

| | 坐标 1 | 坐标 2 |
|---|---|---|
| 变量 | `x`, `y`（储备数量） | `P`, `K`（价格 + 规模） |
| 谁能直接读 | 链上存储 | 链上存储 |
| 谁更直观 | 合约视角 | 人类视角 |

**这个等价关系是理解"K 和价格无关"的关键**，1.6 节会展开。

## 1.4 `x · y = K` 里每个参数到底是什么

### 1.4.1 `x` 和 `y` 是**数量**，不是价格

```
x = 池子里有多少个 A     单位：A（个）
y = 池子里有多少个 ETH   单位：ETH（个）
```

**最常见的误解**：把 `x` 或 `y` 当成价格。

❌ 常见误解：`x` 是 A 的价格，`y` 是 ETH 的价格
✅ 正确理解：`x` 和 `y` 是**数量**。价格是它们的**比值** `y/x`。

### 1.4.2 `K` 的量纲是"面积"，不是价格

`K = x · y`，所以 `K` 的量纲是：

$$[K] = [\text{A 的数量}] \times [\text{ETH 的数量}] = \text{A} \cdot \text{ETH}$$

**注意：这是一个"面积"量纲，不是价格。** 它混杂了两种不同的资产单位。

用主例子 A 验算：`K = 100 A × 10 ETH = 1000 A·ETH`。

**所以 `K` 本身没有"贵不贵"的含义。** 它只说明池子的**规模**。

但 `K` 有一个很有用的性质：**池子总价值的平方根与 `√K` 成正比。**

池子的总价值（以 ETH 计价）：

$$V = x \cdot P + y = x \cdot \frac{y}{x} + y = 2y = 2\sqrt{K \cdot P}$$

在主例子 A 中：`V = 2√(1000 × 0.1) = 2√100 = 20 ETH`。

验算：`100 A × 0.1 = 10 ETH`，加 `10 ETH`，正好 **20 ETH** ✓

> **一句话：`K` 不是价格，是"池子规模"的度量 —— 池子总价值 `V = 2√(K·P)`，在价格不变时 `V ∝ √K`。**

### 1.4.3 `K` 和价格的独立性（本节核心）

把 1.3.3 的推论 3 展开：

$$x = \sqrt{\frac{K}{P}}, \qquad y = \sqrt{K \cdot P}$$

**从这两条公式可以读出 `K` 和 `P` 是两个正交的方向：**

| 你想做的事 | `P` | `K` | 储备怎么变 |
|---|---|---|---|
| 把 A 卖进池子（换出 ETH） | **变** | 名义不变 | 沿同一条曲线滑动 |
| 按比例注入两种币 | **不变** | **变** | 沿同一条射线向外走 |
| 非比例注入 | **也变** | **变** | 既换射线又换曲线 |

```
y (ETH)
^
|                        ╱  射线：同一条射线上 P 相同
|                       ╱
|              ●'      ╱    ●' = 按比例加 LP 后的状态
|             ╱       ╱          （更大 K 的曲线，同一射线 → P 不变）
|            ╱       ╱
|      ●    ╱       ╱       ● = 原状态
|      |╲  ╱       ╱
|      | ╲╱       ╱
|      |  ╲      ╱
|      |   ╲    ╱
|      |    ●  ╱  ← 沿曲线滑动 = swap（P 变，K 不变）
|      |     ╲╱
+------+---------------> x (A)
```

> **一句话：`K` 管"池子多大"，`P` 管"池子在哪一段"。交易只动 `P`，按比例增减流动性只动 `K`。**

## 1.5 价格不是被"存储"的变量：池子不会自己动

这一节澄清一个非常根本的问题。

### 1.5.1 链上存的是什么

合约里存的是**两个数字**：

```
reserve0 = x   （token0 的数量）
reserve1 = y   （token1 的数量）
```

价格 `P = y/x` **不存储在链上**。任何时候需要价格，都是现算的。

> **一句话：合约里没有"价格"这个字段。价格是储备比的定义，每次读取时重新计算。**

### 1.5.2 三个"没有"

既然是"算出来的派生量"，就自然推出三件事：

| 池子里没有的东西 | 为什么 |
|---|---|
| **没有预言机（Oracle）** | 价格不需要从外部获取，它由池子内部的储备比直接定义 |
| **没有 keeper / 机器人** | 没有任何机制"定期"更新价格 |
| **没有自主行为** | 池子不会"觉得价格不对"然后调整自己 |

### 1.5.3 池子只有在收到交易时才会改变

**池子状态的每一次改变，都必须由一笔显式的交易触发。** 可能的入口只有几个：

| 交易 | 效果 |
|---|---|
| `swap` | 沿曲线滑动 |
| `mint` | 注入两种币，曲线外移 |
| `burn` | 取回两种币，曲线内移 |
| `sync` / `skim` | 强制储备与实际余额对齐 |

**没有任何一条路径能让池子"自己想动"。**

```
        外部世界                    池子
     ┌──────────────┐          ┌──────────────┐
     │ 价格在别处变化 │   ✗      │  （毫无反应） │
     └──────────────┘          └──────────────┘
     
     ┌──────────────┐          ┌──────────────┐
     │ 有人发 swap   │   ✓      │  储备被改写   │
     └──────────────┘          └──────────────┘
```

> **一句话：池子是纯被动的。它不"知道"外面的价格 —— 它只是被一笔笔交易推着走。**

**这也意味着：让池子价格回到市价的责任，不在池子身上，而在套利者身上。** 池子自己永远不会主动纠正。

## 1.6 `K` 的真实性质（本章重点）

关于 `K`，流传最广的一句话是"`K` 恒定不变"。**这句话只在最理想的情况下近似成立。** 这一节把 `K` 的三种真实行为分开讲。

### 1.6.1 情况一：单次 swap 内，`K` 名义上不变

在不考虑手续费的理论模型里：

$$(x + \Delta x)(y - \Delta y) = K = x \cdot y$$

两边展开：

$$xy - x\Delta y + y\Delta x - \Delta x \Delta y = xy$$

约掉 `xy`：

$$y \Delta x = \Delta y (x + \Delta x)$$

解出 `Δy`（这就是后文要反复用的成交公式，详见 [02-V2 恒定乘积与无常损失](02-V2-恒定乘积与无常损失.md)）：

$$\boxed{\Delta y = \frac{y \cdot \Delta x}{x + \Delta x}}$$

**所以"`K` 恒定"是一个建模假设，不是物理定律。** 它是我们在推导报价时**故意引入**的条件。

### 1.6.2 情况二：真实的手续费让 `K` 阶梯式递增

现实中每笔交易收手续费 `f`，费用**留在池子里**。有效输入变成 `Δx(1-f)`，但池子实际收到的还是 `Δx`。

新的 `K`：

$$K_{\text{new}} = (x + \Delta x) \cdot \left( y - \frac{y \cdot \Delta x(1-f)}{x + \Delta x(1-f)} \right)$$

化简后得到单笔交易的 `K` 增量：

$$\frac{\Delta K}{K} = \frac{f \cdot \Delta x}{x + \Delta x(1-f)} \approx f \cdot \frac{\Delta x}{x}$$

> **一句话：每笔交易让 `K` 增加一点，增幅约等于"费率 × 这笔交易的相对规模"。`K` 是一条阶梯状上升的曲线，不是常数。**

#### 数值验算（主例子 A，`f = 0.003`）

池子 `100 A + 10 ETH`，`K = 1000`。连续卖入两次 10 A：

**第一笔：`Δx = 10 A`**

$$\Delta x_{\text{eff}} = 10 \times 0.997 = 9.97 \text{ A}$$

$$\Delta y = \frac{10 \times 9.97}{100 + 9.97} = \frac{99.7}{109.97} = 0.906611 \text{ ETH}$$

| 量 | 交易前 | 交易后 |
|---|---|---|
| `x` | 100 A | **110 A** |
| `y` | 10 ETH | **9.093389 ETH** |
| `K` | 1000 | **1000.2728** |

$$\frac{\Delta K}{K} = \frac{0.2728}{1000} = 0.0273\%$$

近似式验算：`f · (Δx/x) = 0.003 × 0.1 = 0.03%` —— 与精确值 `0.0273%` 吻合 ✓

**第二笔：再卖 10 A**

$$\Delta y = \frac{9.093389 \times 9.97}{110 + 9.97} = \frac{90.6610}{119.97} = 0.755698 \text{ ETH}$$

| 量 | 交易前 | 交易后 |
|---|---|---|
| `x` | 110 A | **120 A** |
| `y` | 9.093389 ETH | **8.337691 ETH** |
| `K` | 1000.2728 | **1000.5229** |

$$\frac{\Delta K}{K_{\text{prev}}} = \frac{0.2501}{1000.2728} = 0.0250\%$$

#### 阶梯图

```
K
^
1000.52 |                              ┌────●
        |                             ╱
1000.27 |                  ┌────●────┘
        |                 ╱
1000.00 ●────┐           ╱
        |    └──────────┘
        |
        +--------------------------------------> 交易序号
             初始      第 1 笔      第 2 笔
```

> **一句话：手续费不是"另外收的钱"，它就是 `K` 的增量。`K` 单调不减，只会因为交易而变大。**

**这解释了一件很重要的事**：为什么 LP 代币的价值会**自动上涨**。因为 `K` 变大了，而池子总价值 `V = 2√(K·P)` —— 在价格回到原点时，`V ∝ √K`，所以你的份额对应更多资产。

### 1.6.3 情况三：加减流动性让 `K` 大幅跳变

这是 `K` 变化最剧烈的情形。

**按比例注入**：设你注入了当前储备的 `s` 倍：

$$(x + sx)(y + sy) = xy(1+s)^2$$

$$\boxed{K' = K \cdot (1+s)^2}$$

**按比例撤出**：

$$\boxed{K' = K \cdot (1-s)^2}$$

#### 数值验算（主例子 A）

| 操作 | 储备 | `K` | `P` |
|---|---|---|---|
| 初始 | 100 A + 10 ETH | 1000 | 0.1 |
| 按比例加 10% | 110 A + 11 ETH | **1210** | 0.1 |
| 再撤 10% | 99 A + 9.9 ETH | **980.1** | 0.1 |

验算：`1210 = 1000 × 1.1² = 1000 × 1.21` ✓
`980.1 = 1210 × 0.9² = 1210 × 0.81` ✓

**注意价格那一列：全程 `0.1` 没有变过。** 而 `K` 从 1000 跳到 1210 再跳到 980.1。

```
K
^
1210 |            ●
     |           ╱ ╲
1000 |     ●────╱   ╲
     |          ╲    ╲
 980 |           ╲     ●
     |            ╲
     +------------------------> 操作
        初始   加LP   撤LP
     
        （跳变，不是滑动）
```

> **一句话：交易让 `K` 阶梯式微增；加减流动性让 `K` 一次性大幅跳变。两者是完全不同的量级。**

### 1.6.4 `K` 与价格没有因果关系

这是本章最容易搞错的一点，值得单独说清楚。

**先看一个可能让人困惑的事实**：1.6.3 里，`K` 从 1000 跳到 1210，价格却一动没动。而 1.6.2 里，`K` 只动了 0.027%，价格却变了很多。

**所以 `K` 和价格之间不存在"一个导致另一个"的关系。** 它们是同一个池子的**两个独立坐标**：

$$x = \sqrt{\frac{K}{P}} \qquad y = \sqrt{K \cdot P}$$

给定 `(K, P)`，池子的储备被唯一确定；给定 `(x, y)`，`(K, P)` 也被唯一确定。**这是同一个信息的两种参数化方式。**

```
        (x, y)  ←──────── 等价 ────────→  (K, P)
          │                                  │
      储备数量                        规模 + 价格
          │                                  │
          └──────────┬───────────────────────┘
                     │
        两套坐标，描述同一个池子，没有谁是"因"
```

❌ 常见误解：`K` 变大了所以价格才变 / 价格变了所以 `K` 才变
✅ 正确理解：**`K` 和 `P` 是两个独立维度。** 一次操作改变了 `(x, y)` 这个点，`(K, P)` 作为这点的坐标**同时被确定** —— 谈不上谁导致谁。

> **一句话：`K` 是"池子多大"，`P` 是"池子在哪一段"。它们是同一个点的两组坐标，不存在因果关系。**

## 1.7 操作 → 效果对照表

**这是全文最重要的一张表。** 后面所有章节遇到"某个操作会怎样"，都回到这张表。

| 操作 | `K` | 价格 `P` | 说明 |
|---|---|---|---|
| **交易 swap** | **名义不变**（真实微增 `f·Δx/x`） | **变** | 沿曲线滑动，改变射线斜率 |
| **按比例加 LP** | **变**（`×(1+s)²`） | **不变** | 沿射线外移，换到更大的曲线 |
| **按比例撤 LP** | **变**（`×(1-s)²`） | **不变** | 沿射线内移 |
| **非比例加 LP** | **变** | **也变** | 既换曲线又换射线 —— 见 1.8 |

**用一句话记住这张表：**

> **一句话：swap 改价格不改规模；按比例加减 LP 改规模不改价格；非比例加 LP 两个都改。**

**这张表可以直接回答一类常见疑惑**：

```
"我只是加了个流动性，怎么价格动了？"
  → 因为你加得不成比例（第 4 行）

"我没交易啊，K 怎么变了？"
  → 加/撤流动性本来就会大幅改 K（第 2、3 行）

"交易了半天，K 变了吗？"
  → 变了，但只变了 f·Δx/x 这个量级（第 1 行）
```

## 1.8 非比例加 LP 为什么会改价格

### 1.8.1 现象（主例子 A）

池子：`100 A + 10 ETH`，`K = 1000`，`P = 0.1`

**按比例加**：注入 `+10 A / +1 ETH`

$$110 \text{ A} + 11 \text{ ETH}, \quad K = 1210, \quad P = \frac{11}{110} = 0.1 \ \checkmark \text{ 不变}$$

**非比例加**：注入 `+20 A / +1 ETH`（A 多了，ETH 没跟上）

$$120 \text{ A} + 11 \text{ ETH}, \quad K = 1320, \quad P = \frac{11}{120} = 0.091666\ldots \approx 0.0917$$

$$\Delta P = \frac{0.0917}{0.1} - 1 = -8.33\%$$

> **一句话：注入的 A 和 ETH 不成比例，就相当于"单方面往池子里塞 A"，把 A 的相对价格压低了 8.33%。**

### 1.8.2 几何解释

画在状态图上：

```
y (ETH)
^
|                                  射线斜率 = 0.1（原价格）
|                                ╱
|                              ╱    ● (120, 11)   ← 非比例加点：离开了原射线
|                            ╱     ╱                斜率 = 11/120 = 0.0917
|                          ╱      ╱
|                        ╱       ╱  射线斜率 = 0.0917（新价格）
|                      ╱        ╱
|                    ╱         ● (110, 11)  ← 按比例加点：仍在原射线上
|                  ╱         ╱               斜率 = 11/110 = 0.1
|                ╱          ╱
|              ╱           ● (100, 10)  ← 初始状态
|            ╱          ╱
|          ╱         ╱
|        ╱        ╱
|      ╱       ╱
|    ╱      ╱
+----------------------------------------> x (A)
```

- **按比例加点**：沿着原来那条射线往外走 → 换到更大的曲线，但斜率不变。
- **非比例加点**：**离开了原来的射线** → 斜率变了 → 价格变了，**而且换到了另一条曲线**。

### 1.8.3 多出来的那部分归谁？—— 归老 LP

这一点不直观，但很重要。

v2 的 `mint` 函数在铸造 LP 代币时，用的是**两种币里较小的那个比例**：

```solidity
liquidity = min(
    amount0 * totalSupply / reserve0,   // 按 A 算你能买多少份额
    amount1 * totalSupply / reserve1    // 按 ETH 算你能买多少份额
);
```

在主例子 A 的非比例情形下：

```
按 A  算：20 × totalSupply / 100 = 0.20 × totalSupply
按 ETH 算： 1 × totalSupply /  10 = 0.10 × totalSupply

min(0.20, 0.10) = 0.10 × totalSupply   ← 只按较小的那个给你
```

**也就是说：你交了 `20 A + 1 ETH`，但只按 `10 A + 1 ETH` 给你记份额。多出来的 `10 A` 留在了池子里。**

**这 10 A 变成了全体已有 LP 的资产。**

> **一句话：非比例加 LP 不会报错，但多出来的那部分会被"没收"给老 LP，同时价格被改变 —— 两件事同时发生。**

### 1.8.4 为什么这是个真实的坑

因为套利者会立刻利用被改错的价格。官方文档对此的表述是：

> "When other liquidity providers add to an existing pool, they must deposit pair tokens proportional to the current price. If they don't, the liquidity they added is at risk of being arbitraged as well."
>
> —— Uniswap 官方文档（V2 池概念）

翻译过来：**你非比例加进去，多出的那部分不仅送给了老 LP，还有被套利者二次收割的风险。**

❌ 常见误解：只要保证 `K` 相等就行，怎么加都无所谓
✅ 正确理解：**`K` 相等不是条件，`x : y` 比例才是。** 加流动性必然让 `K` 变大；真正需要保持的是**比例不变**，这才能保证价格不动。

## 1.10 本章要点

1. **池子 = 状态平面上的一个点。** 横轴是 A 的数量，纵轴是 ETH 的数量，点被约束在 `x·y = K` 这条双曲线上。

2. **价格 = 从原点连到该点的射线斜率。** 这是全文的基石：
   $$P = \frac{y}{x}$$
   价格不是一个被存储的字段，而是储备比的定义 —— 每次读取时现算。

3. **`x`、`y` 是数量，`K` 是"面积"量纲。** `K` 本身不含价格信息，它只度量池子规模：`V = 2√(K·P)`，价格不变时 `V ∝ √K`。

4. **池子没有预言机、没有 keeper、不会自主行动。** 状态只能被显式交易（`swap` / `mint` / `burn` / `sync`）改写。让池子价格追上市场的，是套利者，不是池子。

5. **`K` 的三种真实行为**：
   - 单次 swap：**名义不变**（这是建模假设，不是定律）
   - 跨多次 swap：**阶梯式递增**，`ΔK/K ≈ f·(Δx/x)`，手续费就是 `K` 的增量
   - 加减流动性：**大幅跳变**，`K' = K·(1±s)²`

6. **`K` 与价格没有因果关系。** `(x, y)` 与 `(K, P)` 是同一个池子的两套等价坐标：
   $$x = \sqrt{K/P}, \qquad y = \sqrt{K \cdot P}$$

7. **操作 → 效果对照表**（必须记住）：

   | 操作 | `K` | 价格 |
   |---|---|---|
   | 交易 swap | 名义不变（微增） | **变** |
   | 按比例加/撤 LP | **变** | 不变 |
   | 非比例加 LP | **变** | **也变** |

8. **非比例加 LP 有双重代价**：价格被改变（主例子 A 中从 `0.1` 变到 `0.0917`，−8.33%），且多出的那部分份额被记到老 LP 头上（v2 `mint` 取 `min(...)`）。
