## 二、统一记号（不得混用）

| 符号 | 含义 | 备注 |
|---|---|---|
| `x` | 池中 **token0 / 基础币(A)** 的数量 | 不是价格 |

| `s` | 你持有的 LP 份额比例 | |
| `f` | 手续费率 | |
| `r` | 价格倍数 `P₁/P₀` | 用于 IL 公式 |

## 三、统一数值（跨章节必须一致）

### 主例子 A：A/ETH 基础池
```
池子：100 A + 10 ETH
K = 1000
P = 10/100 = 0.1 ETH/A
```
- 加 `+10 A / +1 ETH` → `110 A + 11 ETH`，`K = 1210`，`P` 不变
- 加 `+20 A / +1 ETH` → `120 A + 11 ETH`，`K = 1320`，**`P = 0.0917`（价格变了）**

### 主例子 B：V3 窄区间仓位
```
当前价格 P₀ = 0.1
区间 [p_a, p_b] = [0.05, 0.20]
流动性 L = 10
```
| 价格 P | A 数量 | ETH 数量 | 总价值(ETH) | A 占价值 |
|---|---|---|---|---|
| 0.03 | 22.36 | 0 | 0.671 | 100% |
| 0.05 | 22.36 | 0 | 1.118 | 100% |
| 0.07 | 15.44 | 0.410 | 1.490 | 72.5% |
| 0.10 | 9.262 | 0.926 | 1.852 | 50.0% |
| 0.14 | 4.365 | 1.506 | 2.117 | 28.9% |
| 0.20 | 0 | 2.236 | 2.236 | 0% |
| 0.25 | 0 | 2.236 | 2.236 | 0% |

- 弧的两个端点**精确落在坐标轴上**：`(0, 2.236)` 和 `(22.36, 0)`
- 区间方程：`(x + L/√p_b)(y + L√p_a) = L²`

### 主例子 C：MEME/ETH 往返
```
池子：100 ETH + 1,000,000 MEME
P₀ = 0.0001 ETH/MEME
K = 1e8
用户占 1% → 1 ETH + 10,000 MEME
```
- 涨 50 倍 (P = 0.005)：池子 = `141,421 MEME + 707.1 ETH`，用户 = `1,414 MEME + 7.071 ETH`，**IL = −72.3%**
- IL 表：2× / 5× / 10× / 50× / 100× 各档（见原对话）
- 往返结论：50 倍涨完再跌回原点 → **仓位回到起点，两侧都多约 0.258%**（`K` +0.516%，价值 ∝ √K），**IL → 0**
- 费率陷阱：下行段收的 2,578 MEME，收取时值 1.8 ETH，崩盘后只值 **0.258 ETH（−85.7%）**

### 主例子 D：DAI/USDC 集中流动性
```
$100k 投入 [0.99, 1.01]，P = 1.00
L = 10,024,688
入场 = 49,750.6 USDC + 50,249.4 DAI（注意：不是 50/50）
到达边界时全单边：100,253 USDC / 100,248 DAI
IL ≈ −0.253% / −0.248%
同样资金放 V2：L = 50,000，IL −0.00124%，相差 200.5 倍
资本效率 E = 200.49
举例手续费 $50.12/天，18.3% APR，回本 ≈ 5 天
```

### 主例子 E：V3 区间出界的代价（章节 06 核心）
```
MEME/ETH，入场 P = 1，区间 [0.9, 1.4]，投入 10,000
入场持仓：7,510.6 MEME + 2,489.4 ETH

P = 1.4（刚撞上界）：0 MEME + 11,376.5 ETH
   持币对比 = 7,510.6×1.4 + 2,489.4 = 13,004
   IL = −12.5%

P = 10：0 MEME + 11,376.5 ETH（完全冻结）
   持币对比 = 7,510.6×10 + 2,489.4 = 77,595
   IL = −85.3%

对照组：同样 10,000 放 V2 全区间，P = 10 时 IL = −42.5%
```

### 资本效率表（章节 03 / 06 共用）

**口径统一：`E` 一律在区间的几何均值 $P^* = \sqrt{p_a p_b}$ 处取值。**
（$P^*$ 恰为「仓位 50/50」的价格点，也是通用式与化简式一致的口径。）

| 区间 | 宽度 | 几何均值 $P^*$ | E |
|---|---|---|---|
| [0.05, 0.20] | ×2 / ÷2 | 0.100000 | 3.4× |
| [0.08, 0.125] | ±22% | 0.100000 | 9.5× |
| [0.09, 0.11] | ±10% | 0.099500 | 20.4× |
| [0.099, 0.101] | ±1% | 0.099995 | **200.5×** |

> ⚠️ **口径提示**：若改用 $P = 0.1$ 计算，第 3 行是 19.5×、第 4 行是 199.5×。两种口径结论一致（都是数量级提升），但**全书必须统一用几何均值口径**。
> 第 4 行的 **200.5×** 与主例子 D（DAI/USDC）的 `E = 200.49` 同源，务必保持一致。

**化简式**：令 $w = \sqrt{p_b / p_a}$，则 $E = \dfrac{\sqrt{w}}{\sqrt{w} - 1}$；窄区间下 $E \approx 2/\delta$。
**直觉**：区间宽度减半 → 资本效率约翻倍。

### 区间寿命表（章节 06 核心）
`E[T] ≈ δ²/σ²`

| 资产 | 日波动率 σ | 区间半宽 δ | 期望出界时间 |
|---|---|---|---|
| 稳定币 | 0.1% | ±1% | ~100 天 |
| ETH | 3% | ±10% | ~11 天 |
| ETH | 3% | ±3% | ~1 天 |
| MEME | 30% | ±10% | **~2.7 小时** |
| MEME | 30% | ±50% | ~2.8 天 |

### 最优区间宽度（章节 06 核心）
`δ* ≈ σ√H`

| 资产 | σ（日） | H | δ* | 价格区间 |
|---|---|---|---|---|
| 稳定币 | 0.1% | 30 天 | 0.55% | [0.995, 1.006] |
| ETH | 3% | 30 天 | 16.4% | [0.85, 1.18] |
| ETH | 3% | 7 天 | 7.9% | [0.92, 1.08] |
| MEME | 30% | 1 天 | 30% | [0.74, 1.35] |
| MEME | 30% | 7 天 | 79% | [0.45, 2.21] |

### tick 数值（均已对照 v3-core 源码核对）
- `P(i) = 1.0001^i`
- tick −100 ≈ 0.99005，tick +100 ≈ 1.01005
- tick ±60 ≈ [0.99402, 1.00602]，tick ±10 ≈ [0.99900, 1.00100]，tick ±1 ≈ [0.99990, 1.00010]
- tickSpacing：0.01% → 1，0.05% → 10，0.30% → 60，1.00% → 200
- `MIN_TICK / MAX_TICK = ∓887272`，可表示价格约 `2⁻¹²⁸ ~ 2¹²⁸`
  （上限由 `sqrtPriceX96` 必须塞进 `uint160` 决定）
- **`tickSpacing` 有硬上限 `16384`**；源码注释给出原因：超过会让
  `TickBitmap#nextInitializedTickWithinOneWord` 溢出 `int24`。
  注释同时标定「16384 ticks ≈ 5 倍价格变化」。
- 费率上限：`fee < 1000000`（以百万分之一为单位）
- **成因备注**：`0.01% → tickSpacing 1` 这一档**不在** `UniswapV3Factory` 的构造函数里。
  构造函数只内置 `500→10`、`3000→60`、`10000→200` 三档；
  `0.01%` 是部署后由 owner 调 `enableFeeAmount(100, 1)` 追加的。
  四档表描述的是最终状态，但成因值得记一笔。

### Hook 权限位（章节 05 核心，源码原文，不得改动）
```
ALL_HOOK_MASK = (1 << 14) - 1

BEFORE_INITIALIZE_FLAG       = 1 << 13   // 0x2000
AFTER_INITIALIZE_FLAG        = 1 << 12   // 0x1000
BEFORE_ADD_LIQUIDITY_FLAG    = 1 << 11   // 0x0800
AFTER_ADD_LIQUIDITY_FLAG     = 1 << 10   // 0x0400
BEFORE_REMOVE_LIQUIDITY_FLAG = 1 << 9    // 0x0200
AFTER_REMOVE_LIQUIDITY_FLAG  = 1 << 8    // 0x0100
BEFORE_SWAP_FLAG             = 1 << 7    // 0x0080
AFTER_SWAP_FLAG              = 1 << 6    // 0x0040
BEFORE_DONATE_FLAG           = 1 << 5    // 0x0020
AFTER_DONATE_FLAG            = 1 << 4    // 0x0010
BEFORE_SWAP_RETURNS_DELTA_FLAG             = 1 << 3  // 0x0008
AFTER_SWAP_RETURNS_DELTA_FLAG              = 1 << 2  // 0x0004
AFTER_ADD_LIQUIDITY_RETURNS_DELTA_FLAG     = 1 << 1  // 0x0002
AFTER_REMOVE_LIQUIDITY_RETURNS_DELTA_FLAG  = 1 << 0  // 0x0001
```
- 示例地址 `0x...2400` → `0x2400 = bit13 + bit10` → `beforeInitialize` + `afterAddLiquidity`
- `beforeSwap` 返回恰好 **96 字节**；`afterSwap` 返回恰好 **64 字节**
- 动态费率覆盖的 uint24 需**次高位（23 位，0x400000）**置位，且值 ≤ 1,000,000
- 挖地址期望尝试次数 ≈ `2^14 = 16,384`

## 四、统一公式（必须使用这些形式）

```
恒定乘积          x · y = K
价格（定义）       P = y / x
价格与 K 的换算    x = √(K/P)      y = √(K·P)
滑点              Δy = y·Δx/(x+Δx)
平均成交价         y/(x+Δx)        （永远差于现货 y/x）
边际价格          −dy/dx = y/x
价格冲击          ΔP/P ≈ 2·Δx/x
往返定律          P/P₀ = ((y₀+E)/y₀)²     （E = 累计净 ETH 流入）
移除比例 a 后      价格倍数 = 1/(1−a)²
LP 持仓           ETH = s·√(K·P)     A = s·√(K/P)
数量比            ETH/A 数量比 = P
K 增长            ΔK/K ≈ f · (Δx/x)
加/撤流动性        K' = K·(1±s)²
无常损失          IL(r) = 2√r/(1+r) − 1
V3 流动性         L = √(x_virtual · y_virtual)
V3 实际储备       x_real = L(1/√P − 1/√p_b)     y_real = L(√P − √p_a)
端点取值          P=p_a 时 x_real = L(1/√p_a − 1/√p_b)，y_real = 0
                  P=p_b 时 y_real = L(√p_b − √p_a)，x_real = 0
tick 价格         P(i) = 1.0001^i
资本效率          E = 1/(1 − √(p_a/P))
几何均值处         V = 2L(√P − √p_a)   （P = √(p_a·p_b)）
区间寿命          E[T] ≈ δ²/σ²
最优半宽          δ* ≈ σ√H
V3 价格冲击       Δ√P = Δy/L  ⟹  ΔP/P = 2Δy/(L√P)
V4 复合费率       swapFee = protocolFee + lpFee − protocolFee·lpFee/1_000_000
V4 协议费上限      0.1%（1000 pips）
```

## 五、统一文风

### 必须遵守

1. **中文写作**。术语首次出现时给出英文原文，例如「无常损失（Impermanent Loss, IL）」。
2. **每个结论都要有推导或数值验证**。这是用户明确要求的（"保留完整推导"）。
3. **关键结论用引用块收束**：
   ```
   > **一句话：……**
   ```
4. **对比用表格**，结构用列表，流程用代码块画的图。
5. **公式用 LaTeX**：行内 `$P = y/x$`，独立成行 `$$IL(r) = \frac{2\sqrt{r}}{1+r} - 1$$`
6. **数值必须标注单位**，如 `0.926 ETH`、`9.262 A`。
7. **主动指出不确定性**。凡是有争议、未验证、或依赖具体版本的内容，必须显式标注：
   ```
   > ⚠️ **未验证**：……
   ```
7b. **溯源标记（判断密集的章节使用）**。对于「机制分析 / 生态对比 / 归因判断」这类
   无法只用公式收束的章节，除了上面的未验证块，还可用**行内方括号标记**区分结论的来源性质。
   07 章首次使用，现正式采纳为全书约定：

   | 标记 | 含义 | 读者该怎么对待 |
   |---|---|---|
   | `[推导]` | 从本套文档已建立的机制推出 | 可自行验证 |
   | `[事实]` | 有明确机制或公开源码支撑 | 可去对照源码 |
   | `[推理]` | 结构性分析，逻辑成立但无一手数据 | **仅供思考** |
   | `[⚠️ 未验证]` | 无可靠来源 | **不得作为决策依据** |

   使用这一套标记的章节，必须在开头用引用块给出上表作为图例
   （见 `07-生态-以太坊与Solana.md` 开头）。
   纯数学推导章节（01 / 02 / 03 / 06）**不需要**这些标记 —— 那里的每条结论都可当场验算。
8. **纠正错误的旧认知**时，用「❌ 常见误解 → ✅ 正确理解」的格式。
9. 每章开头写一段 **「本章回答什么问题」**，结尾写 **「本章要点」**。
